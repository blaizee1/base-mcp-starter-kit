# Base MCP Starter Kit; DeFi Yield Optimizer Agent

Zero-code starter for Base MCP (launched May 26, 2026).  
Turn Claude, Cursor, or ChatGPT into an autonomous DeFi yield optimizer on Base using official native plugins.

## Quick Start (2 minutes)
1. Go to [base.org/agents](https://www.base.org/agents)
2. Click **Add to Claude** (or follow instructions for Cursor/ChatGPT/Claude Code)
3. Run this command in your AI client terminal (or use the skill installer): npx skills add base/skills --skill base-mcp


4. Connect your Base wallet when prompted.

You now have native onchain powers: check yields, swap, lend, provide liquidity; **all via natural language**.

## Official Native Plugins Included
- Morpho → best vaults & lending
- Moonwell → supply/borrow
- Uniswap → swaps + LP
- Aerodrome → liquidity + swaps
- Avantis → perps
- Bankr → new token launches
- Virtuals → agent-to-agent coordination
